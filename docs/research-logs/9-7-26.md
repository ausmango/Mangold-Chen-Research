## 2026-09-07 — Moondream2 FP16 Baseline

### Configuration

- Device: NVIDIA Jetson Orin Nano, 8 GB unified memory
- Model: `vikhyatk/moondream2`
- Revision: `2025-04-14`
- Precision: FP16
- Framework: PyTorch 2.8.0 with CUDA 12.6
- TorchVision: 0.23.0
- Transformers: 4.57.6

### Results

Moondream2 successfully loaded once in FP16 after closing major applications.
PyTorch reported 3.59 GiB of allocated GPU memory.

However, repeated subsequent loading attempts failed with:

`NvMapMemAllocInternalTagged: error 12`

and:

`NVML_SUCCESS == r INTERNAL ASSERT FAILED`

The failures occurred both during Transformers' allocator warm-up and during
actual model-weight loading. Skipping the optional allocator warm-up did not
resolve the weight-loading failure.

### Finding

The unquantized FP16 model is technically capable of loading, but it is not
reliably usable under the Jetson's normal graphical desktop environment.
The available unified memory leaves insufficient reliable headroom for model
loading and image inference.

No FP16 inference latency or output-quality baseline was collected because
the model could not be loaded consistently enough to reach inference.

### Decision

Proceed with weight quantization and test whether reduced-precision loading
provides reliable model initialization and enough memory for image inference.
If a complete FP16 inference baseline is later required, it may need a
headless environment or administrator assistance to reduce system memory use.
